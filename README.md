# 📚 WebToon App

A simple web application for reading and managing comics, built with **React** on the frontend and **Django** on the backend.

---

## 🚀 Tech Stack
- **Frontend:** React
- **Backend:** Django
- **Database:** PostgreSql

---

⚙️ Setup & Run

### 🔹 Frontend
cd frontend
npm install
npm run dev
### 🔹 Backend
cd backend 
python3 -m venv venv source venv/bin/activate 
python manage.py runserver
